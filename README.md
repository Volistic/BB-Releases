# Badge & Build — downloads

Badge & Build is a 2D block sandbox (dig, build, explore, fight bosses) that started on a
conference badge and now runs on PC, with online multiplayer.

**➡ [Download the latest release](../../releases)**

> Everything here is a **beta** for now. Expect bugs and changes.

## Playing

1. Download `BadgeBuild-windows.zip` from the [releases](../../releases).
2. Unzip it anywhere and run `BadgeBuild.exe`. No install, no Python.
3. If Windows says "Windows protected your PC" (the program isn't signed), click
   **More info → Run anyway**.

Your worlds, name and settings are kept in `%APPDATA%\BadgeBuild`, not in the game folder.
A new version keeps them: unzip it anywhere and play.

**Older versions:** on the start screen, **Version** lists the releases you can play. If you
join someone's game on a different version, your game switches to it for that game.

## Running a server

Download `BadgeBuildServer-windows.zip` and read `README.md` inside. It covers setting up a
free playit.gg tunnel (no port forwarding), the dedicated world, ops, commands and plugins.

## Problems

[Open an issue](../../issues). Note which release you're using (it's in the zip's name and on the release page) and what
happened. For multiplayer issues, include `game.log` from `%APPDATA%\BadgeBuild`.
